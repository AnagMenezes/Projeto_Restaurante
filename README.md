# Sistema de Restaurante

Projeto de um sistema para gerenciamento de restaurante, desenvolvido com o objetivo de colocar em prática conhecimentos de **Java, Spring Boot, APIs REST e bancos de dados**.

O projeto está sendo desenvolvido gradualmente, começando pela estrutura do backend e pela modelagem do banco de dados. A intenção é continuar expandindo o sistema até chegar a uma aplicação completa e funcional. Podendo ser um projeto em potencial para o mercado local.

## Status do projeto

**Em desenvolvimento**

O projeto ainda está em construção e novas funcionalidades serão adicionadas ao longo do desenvolvimento.

## Objetivo

Desenvolver um sistema capaz de auxiliar no gerenciamento de um restaurante, trabalhando com produtos, categorias, pedidos e seus respectivos itens.

Além de desenvolver a aplicação, o projeto também tem como objetivo explorar conceitos de **arquitetura de software, persistência de dados e desenvolvimento de APIs**.

## Tecnologias

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* Maven

## Estrutura atual

O projeto está sendo organizado seguindo uma separação de responsabilidades entre as principais camadas da aplicação:

* **Entity** — representação das entidades do sistema
* **Repository** — acesso e persistência dos dados
* **Service** — regras e lógica de negócio
* **Controller** — comunicação através da API REST
